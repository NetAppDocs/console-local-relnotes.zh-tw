=== 備份與還原



==== Kubernetes 工作負載增強功能

在此版本中，NetApp Backup and Recovery 針對 Kubernetes 工作負載引入了以下增強功能：

* *Amazon FSx for NetApp ONTAP 支援磁碟對磁碟備份架構*：您現在可以建立 Kubernetes 保護原則，這些原則使用磁碟對磁碟備份架構，並以 Amazon FSx for NetApp ONTAP 作為主儲存設備，以及將另一個 FSx for NetApp ONTAP 檔案系統作為次要儲存設備，位於同一個 AWS 區域或不同的 AWS 區域。您也可以使用 Cloud Volumes ONTAP 作為主儲存設備，並將 FSx for NetApp ONTAP 作為次要儲存設備。
* *修正 qtree 還原問題*：ontap-nas-economy Volume 還原先前會還原擁有者和權限不正確的 qtree 目錄。此問題已在此版本中解決。


如需建立 Kubernetes 保護原則的詳細資訊，請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-policies-kubernetes-create.html["在 NetApp Backup and Recovery 中建立及管理 Kubernetes 備份原則"^]。

有關保護 Kubernetes 工作負載的詳細資訊，請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html["了解如何使用 NetApp Backup and Recovery 保護 Kubernetes 工作負載"^]。



==== ONTAP Volumes 工作負載增強功能

在此版本中，NetApp Backup and Recovery 針對 ONTAP Volumes 工作負載引入了下列增強功能：

* *還原介面改進*：ONTAP Volume 的還原精靈採用了全新的版面配置與改進的導覽：
+
** *改進的選擇表格*：選擇表格一次顯示更多列與欄。還原畫面採用更優化的間距和導覽路徑，讓您能了解自己目前在工作流程中的位置。
** *逐步導覽*：*下一步*和*繼續*按鈕的功能已改進，避免您意外跳到下一個主要步驟。*上一步*按鈕會將您帶回上次完成的畫面，並保留您先前的選擇，因此您無需重新啟動該步驟。
** *選擇來源 Volume 時可查看更多詳細資訊*：Volume 清單現在顯示 Volume 類型、Volume 樣式、SnapLock 類型、現有保護和保護健全狀況。「現有保護」欄位更寬，因此您可以查看所有保護指標（快照、複寫和備份）。


* *支援保護託管在 Azure 中國區域的 Volume*：您現在可以將 ONTAP Volume 備份到 Azure 中國（世紀互聯）的 Azure Blob 儲存設備。此支援適用於 Cloud Volumes ONTAP 和內部部署 ONTAP 系統。商業 Azure 和 Azure 政府區域保持不變。


有關保護 ONTAP Volumes 工作負載的詳細資訊，請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html["了解使用 NetApp Backup and Recovery 的 ONTAP Volume 保護"^]。

==== Kubernetes 工作負載增強功能

在此版本中，NetApp Backup and Recovery 針對 Kubernetes 工作負載引入了以下增強功能：

* *Trident Protect 26.10*：此版本包含 Trident Protect 26.10。
* *ontap-nas-economy 和 ontap-san-economy 驅動程式支援*：現在您可以保護由 NetApp Trident `ontap-nas-economy` 驅動程式（Qtree）和 `ontap-san-economy` 驅動程式（LUN）配置的持續性 Volume 宣告（PVC）。使用經濟型驅動程式保護 PVC 時，整個底層 FlexVol 或 LUN 都會受到保護。您可以從這些備份中還原個別的 PVC。
* *Kubernetes 感知警告*：警告現在每個 Kubernetes 應用程式發送一次，而不是每個 Volume 發送一次。
* *Volume 群組快照支援*：現在您可以在定義 Kubernetes 應用程式時建立 Volume 群組。Volume 群組可讓您將多個 Volume 一起快照為損毀狀況一致的集合，確保群組內所有 Volume 的資料一致性。
* *S3 相容物件儲存支援*：您現在可以透過新增備份目標認證資料和設定保護原則，將 Kubernetes 應用程式資源和資料備份到 S3 相容物件儲存。


有關保護 Kubernetes 工作負載的詳細資訊，請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html["了解如何使用 NetApp Backup and Recovery 保護 Kubernetes 工作負載"^]。



==== ONTAP Volumes 工作負載增強功能

在此版本中，NetApp Backup and Recovery 針對 ONTAP Volumes 工作負載引入了下列增強功能：

* *保護報告*：NetApp Backup and Recovery 現在支援建立和下載 ONTAP Volumes 工作負載的擴充報告。
* *註銷 ONTAP 系統時保留備份*：現在，當您從 NetApp Backup and Recovery 註銷 ONTAP 系統時，您可以選擇捨棄先前備份的資料，或將其保留以供還原。NetApp Backup and Recovery 文件現在包含有關在系統註銷後使用 ONTAP CLI 還原保留資料的說明。


更多詳情請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-backup-manage.html#unregister-netapp-backup-and-recovery-for-a-system["取消註冊系統的 Backup and Recovery"^]。

有關保護 ONTAP Volumes 工作負載的詳細資訊，請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html["了解使用 NetApp Backup and Recovery 的 ONTAP Volume 保護"^]。

==== ONTAP Volumes 工作負載增強功能

在此版本中，ONTAP Volumes 工作負載引入了以下預覽增強功能：

* *改進對隔離站台的支援*：適用於隔離站台的 NetApp Backup and Recovery 現在提供與 NetApp Backup and Recovery 相同的 ONTAP Volumes 資料保護功能。此增強功能包括更新的備份、還原和作業管理服務以及新的中繼資料資料庫。升級期間，現有資料庫資料將保留並自動移轉。升級後，審查稽核記錄以驗證移轉是否成功完成。適用於隔離站台的 NetApp Backup and Recovery 僅支援 ONTAP Volumes 工作負載。
* *取消 Volume 還原作業*：現在可以從作業監控頁面取消後續的 ONTAP Volume 還原作業，更容易管理長時間運作或運作緩慢的作業。
* *改進的 Volume 索引狀態報告*：ONTAP Volumes 儀表板現在透過針對不符合索引條件的 Volume 和快照複本引入 `Not Applicable`狀態，更準確地報告索引狀態。此 `Not Indexed`狀態現在保留給等待索引的 Volume，且 Volume 詳細資料現在會顯示每個快照的索引狀態，並帶有懸停文字來解釋為何 Volume 或快照複本不會被索引。
* *NetApp AFX 支援*：您現在可以保護託管在 2 節點和 4 節點 NetApp AFX 叢集上的 Volume。


有關保護 ONTAP Volumes 工作負載的詳細資訊，請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html["了解使用 NetApp Backup and Recovery 的 ONTAP Volume 保護"]。



==== Kubernetes 工作負載增強功能

在此版本中、Kubernetes 工作負載引入了以下增強功能：

* *Trident Protect 26.09*：此版本包含 Trident Protect 26.09。
